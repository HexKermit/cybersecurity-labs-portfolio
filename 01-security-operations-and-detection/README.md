# Security Operations and Detection Labs

## Overview

This section contains hands-on defensive security investigations, detection analysis workflows, and DFIR-focused security labs.

The projects focus on:
- incident response workflows
- IOC correlation
- memory forensic analysis
- persistence investigation
- network traffic analysis
- defensive monitoring
- detection visibility
- SIEM and log analysis concepts

The investigations were performed within controlled lab environments for defensive security training and forensic analysis practice.
